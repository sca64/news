Cet article sert uniquement à valider la chaîne complète : un fichier Markdown ici, un git push, et le texte apparaît dans un lecteur RSS sur iPhone.

Le flux contient le texte intégral de chaque article dans content:encoded. Si l'application préfère extraire le texte depuis la page liée, elle trouvera une page HTML propre avec exactement le même contenu.

Ce qui est testé

  • le contenu intégral dans le flux ;
  • les caractères accentués, y compris dans le titre ;
  • les liens, comme celui vers l'index ;
  • une liste, un paragraphe, et du texte en gras.

Le reste suivra quand il y aura de quoi en faire un second.
