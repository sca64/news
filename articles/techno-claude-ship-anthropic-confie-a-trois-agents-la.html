Claude Ship : Anthropic confie à trois agents la validation des pull requests

24 novembre 2026

Jusqu'à présent, un développeur qui faisait appel à Claude pour générer du code devait garder la main jusqu'au bout : le modèle produisait les lignes, mais un humain avait le dernier mot avant la mise en production. Anthropic veut désormais lever ce verrou avec Claude Ship, présenté ce lundi 23 novembre.

Le principe est celui d'une chaîne de trois agents qui se relaient après l'ouverture d'une demande de fusion sur GitHub. Le premier inspecte les modifications, le second répare ce qui coince, le troisième décide — si l'équipe le souhaite — de donner lui-même le feu vert final. En interne, Anthropic dit avoir doublé le nombre de modifications intégrées tout en réduisant la casse.

Next, qui couvre également l'annonce, précise que la mission assignée à Ship est de « relire le code, corriger les problèmes et décider si la demande peut être fusionnée », un périmètre qui englobe tout ce qui se passe après l'ouverture d'une pull request.

L'outil s'inscrit dans la flotte de services Claude déjà déployés par l'entreprise. Le fait que la décision finale de fusion puisse être déléguée à un agent, plutôt que systématiquement conservée par un développeur, constitue le point de bascule : le dernier verrou humain devient optionnel, dépendant du réglage choisi par l'équipe.

Anthropic ne détaille pas dans ces dépêches les tarifs ni les conditions d'accès à Ship, ni les garde-fous prévus pour éviter qu'un agent valide une modification défaillante en l'absence de revue humaine.
